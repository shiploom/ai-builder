# Shiploom documentation

Shiploom Core is a portable, zero-runtime method layer for building software
with AI harnesses: Specifier → Implementer → Verifier plus a deterministic
orchestrator and human gates.

- [Consumer manual (J1–J4)](./manual): idea to MVP, brownfield fixes, team
  features, enterprise hardening.
- [Install](./install): pipx, uvx, source, and verifying your install.
- [Policy cookbook](./policy-cookbook): default-deny packs, gates, approvals.
- [Brownfield playbook](./brownfield-playbook): map, impact, characterize,
  change, verify.
- [Cost / escape dashboard](./cost-dashboard): the metrics contract.
- [Release process](./release): versioning, tagging, signing.

The Markdown sources of truth live in `docs/` at the repo root; these pages
are generated by `npm run docs:sync` (drift-checked in CI).
