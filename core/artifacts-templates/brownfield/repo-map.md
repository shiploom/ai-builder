# Repository map

> Grounded in the symbol graph + build + test evidence, not a file list.
> Low-confidence areas are marked and narrow downstream write scopes.

## Structure

Top-level layout, ownership, entry points.

## Architecture and conventions

Layering, patterns, naming, testing, and error-handling conventions.

## Dependencies and behavior

External services, data flows, background jobs, feature flags.

## Debt and risks

Known debt with file:line refs (mirror in `debt-register.md`).

## Confidence notes

Areas the map is unsure about and what would raise confidence.
